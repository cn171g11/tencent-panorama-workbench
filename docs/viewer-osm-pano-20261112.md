# v2.38.0 网页查看器功能更新

## 新增

- 底图选择器新增 `OSM·亮色`，使用 OpenStreetMap 标准瓦片。
- 底图选择器新增 `OSM·暗色`，使用 CARTO Dark Matter 瓦片。
- 详情弹窗新增 `本地查看六面` 按钮，不改变已有布局和原有外链按钮。
- 新增 `city-viewer/pano.html` 独立查看页，使用本地 Pannellum 资源显示 cubemap。
- 六面请求按 `face=1..6`、每面 `2×2` 瓦片拼接；支持含字母的 ID，例如 `310730J3150611122702000`。

## 约束

- OSM/CARTO 底图均为公开第三方瓦片，页面保留来源归属；服务可用性不由本项目保证。
- 六面影像请求依赖 `streetapi.ishowchina.com` 的跨域和接口可用性；失败时页面提示错误，并可回到原有外部街景入口。
- 本次只修改网页查看器，不修改点位数据、Android、iOS 或 PC 私有工程。
