# 上海全市隐藏查看与直辖市区级报告修复

## 查看器

[查看器](<../city-viewer/index.html>) 的 `hidden_310000` 原来只匹配市级旧集合（1点），不包含上海16区隐藏集合。本次保持所有原始集合和点位不动，只扩展直辖市市级隐藏选择作用域：

- “上海市·全部隐藏街景”覆盖上海市名下的市级与区级隐藏集合，修复前基线共4,487点；单独选择浦东等区仍只显示该区。
- 同一规则适用于北京、天津、重庆市级隐藏选项。匹配同时检查隐藏行政码和元数据省份；不纳入常规点、邻省近名键或独立游戏集合。
- 概览、明细读取、道路过滤、底层散点与定位范围采用同一作用域；不复制点位或改写分类。
- v2.46.0的默认空图、准备范围0街景请求、明确确认后仅网格及按需明细行为继续保留。

## 数据报告

[报告](<../city-viewer/report.html>) 原来按集合 `pref` 直接汇总：直辖市常规分片是市级码，隐藏有区级码，导致区行常规初值0被误当实测计数。本次不按面积均分或网格中心估算，新增小型 [区级派生元数据](<../city-viewer/municipality-report.js>)。

[生成器](<../tools/build_municipality_report.js>)限定选择四直辖市元数据名下的全部常规分片（含`qq_<省码>`）和隐藏集合，逐原始GCJ-02坐标匹配冻结DataV区县面。外环减洞、MultiPolygon岛面完整；共享边或顶点按最低区码稳定唯一归属。严格面外点保留为“未归属区县／边界外”，不最近猜区、不转移邻市、不丢点。

统计口径是“存储在本直辖市名下的数据按区县细分”，不宣称已重新定位其他省文件内所有可能落在该市的点。四市常规与隐藏分别满足：区县之和＋残差＝本市源集合总数。报告区行替换原混合子行，省级与全国总数仍直接由`PANO_COUNT`汇总，不重复累计。

基线读取10,011,498条，132集合／60物理源，点源字节不变；区县目录北京16、天津16、上海16、重庆38。统计结果约17KB，报告不读取点数组、grid或search。真正已统计为0的重庆区县仍显示0，不为消除数字0伪造点数。

## 有界计算与一致性

- 逐行64KiB解析，只持区县面、整数计数与固定容量空间候选缓存；可确定整单元内部成员恒定的拓扑证明才复用，否则逐点精确几何。
- 残差立即JSONL落盘，缓存仅含计数及sidecar SHA；绑定几何实现指纹，源SHA/计数/边界变更拒绝复用。
- [显示验证模块](<../city-viewer/municipality-report-view.js>)检查分类守恒和本市全部源键计数；正式发布还核对同清单源SHA及bytes。缺失／过期统计折叠回已知市级合计并提示“区级统计未就绪”，不生成假0。
- [发布器](<../tools/build_gzip_site.py>)在成功标记前检查统计meta SHA、源SHA／bytes与区级分类守恒。统计文件不命名`data_*.js`，不加入`PANO_COUNT`为虚拟点源。
