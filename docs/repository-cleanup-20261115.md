## 3. 判断依据与保留边界

### 腾讯旧点位的归并：复用历史证据，不重做结论

[2026-11-03合并报告](<gansu-heilongjiang-import-20261103.md#L27-L40>)记录：漠河、额尔古纳、加格达奇、塔河旧集合归并正式城市层后删除，高淳此前已归并；G312与溧水线路点最后31个遗漏记录按常规29/隐藏2分流。清理基线中的旧目录已不跟踪那些腾讯点位清单和分片。

本轮核对的是当前文件清单、结构、引用和既有报告，**没有重新读取已删除的所有旧扫描原件逐SID核对**，不宣称新林或呼玛历史扫描源全部验收。正式点库本轮保持不变，不需要重复全库SID审计。

### 旧边界和线路仍有独立价值

在整理基线中，对旧根目录文件与查看器既有文件的Git blob ID清单作比较，没有完全相同副本。六个能按行政码对应的旧区域边界与[正式区县边界](<../city-viewer/data_districts.js>)的坐标数组也不相同：

这是“不是相同副本”的证据，不判定哪个版本更权威。保留原件供追溯，不替代正式边界、不重新生成旧点位层。7份历史README中的旧文件清单、图片下载、扫描限流、未完成项目均为当时记录，不能作为当前文件存在或自动续跑的依据。

### 新林来源错配：明确疑点，不改字节

[历史新林README](<../city-viewer/legacy/tencent/xinlin/README.md>)称新林区232723，但[同名边界](<../city-viewer/legacy/tencent/xinlin/xinlin-boundary.geojson>)解析出的属性为：

```json
{"地名":"漠河县","区划码":"232723","县级":"漠河县","县级码":"232723","year":"2017","eng_name":"Mohe"}
```

现行查看器区县元数据没有同码232723记录。归档按历史目录名保留，不根据文件名认定它是现行新林边界，也不根据这条疑点自动纠正坐标或新增点位。

### 百度单独隔离；溧水分类纠正

[S341百度JSON](<../city-viewer/legacy/baidu/s341/s341-baidu-panoramas.json>)包含 **1,718 条panoramas、493 条历史errors**及内嵌OSM路线，声明坐标来自百度BD09MC，经BD09LL转换为WGS84。原件还明确告诫需人工审查后才能声称完整覆盖。本次不修改其坐标、provider或错误记录，也不把它加入腾讯集合、计数、搜索、网格。

[南京溧水线路](<../city-viewer/legacy/tencent/lishui-panorama/lishui-tencent-lines.geojson>)为腾讯线路；旧页面也只把来源声明为Tencent。当前说明已纠正此前把溧水与S341一起概括为百度资料的错误。此次本地归档不表示这些S341数据已迁入或核验于另一独立百度仓库。

### 退休页面不含唯一内嵌点位，但不是“全都失去功能”

逐份静态检查8份HTML：点位/来源/线路初始数组为空，无实际SID常量、内嵌点库、JSON脚本块或编码数据载荷。数据来自外置JSON/GeoJSON、用户导入、浏览器localStorage，或G212的实时API。旧页面引用的44份腾讯分片，以及G212、S341各1份腾讯JSON，在整理前均已不存在。

退休理由是将活动入口统一到全国查看器，而非宣称代码没有任何独立功能：G212仍包含需要另行授权和配置的实时采样UI；S341仍可读取保留的百度JSON。对应的[G212 CLI](<../tools/g212-scan.mjs>)和[区域采集工具](<../tools/city-scan/>)继续保留。页面代码保留在Git历史即可恢复；本轮不读、不改、不清空浏览器localStorage，也不声称已经迁移用户本地编辑。

## 4. 非加载、非发布与轻量验证

[历史归档](<../city-viewer/legacy/>)只存源码资料，不作为正式查看器的集合或资源目录，不改数据元信息来注册它。现有[发布器](<../tools/build_gzip_site.py>)由顶层点位清单与前端静态白名单构建，正式[Pages工作流](<../.github/workflows/pages.yml>)只上传独立Brotli产物；根旧工作台本来不在该产物中。因此本次源码搬迁和420,405 B退休文件**不代表线上包体减少**。

本次验收限于精确文件映射/大小/哈希、27份原件字节一致、退休HTML无唯一内嵌点位、当前指南链接和发布边界、最终diff白名单及受保护工作区未变。相关发布/归档夹具 **66 项 Python、22 项 Node 全部通过**；检查覆盖gzip/Brotli归档排除、旧地址跳转和交接门禁，活动点位/前端变更仍会阻断过期交接。

没有重新运行全库点位搜索、SID扫描、索引重建、Brotli重压或腾讯/百度采集API，也不把既有线上验收记录当作本次新测。源码整理推送后仅核对远端提交/根目录与未变的线上入口、元信息、资源清单，不宣称重新下载全526资源或做新一轮浏览器数据验收。
