## 无损与低内存处理

- 复用旧准备库，在应用前将 43 个准备分片的 4,749,762 条最终行与 SQLite union按 SID顺序逐条比较，原 JSON行相等；分片上限18万。
- 旧 metadata SHA、准备文件全集与哈希通过后，备份全部44个替换目标和2个删除目标；应用失败可回滚，不覆盖用户线路或私有工程。
- 全库排除按候选 SID流式查找，不把近五千万 SID放进一个内存集合；索引、全库SID和网络审计不并发。
