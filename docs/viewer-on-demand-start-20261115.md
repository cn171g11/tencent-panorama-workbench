# 查看器：先选择视图，再加载街景（v2.46.0）

## 启动行为

首次打开 [查看器](<../city-viewer/index.html>) 只初始化空地图、已有元数据与选择控件，并显示“先选择视图”提示。

1. 在顶部选择全国或省份；选择省份后可进一步选择城市。
2. 选择过程只准备范围，不下载街景资源。
3. 点击 **加载所选视图** 才下载并校验概览网格，再显示该范围。
4. 查看散点/区县明细或执行搜索时，才按需读取常规点位、隐藏合集和搜索索引。

未选择范围时确认按钮禁用；首次确认前搜索及散点模式禁用。小范围概览的首次自动定位限制到14级，避免程序性缩放立即触发明细下载。启动失败恢复选择控件和空视图，提供原范围重试，不把错误当作零命中。

“默认不加载任何街景”指没有点位分片、隐藏合集、网格或搜索索引请求；元数据、行政边界、Leaflet及底图仍可能产生网络请求，不是零总网络流量。既有Brotli压缩/大小/双SHA校验不变。

## 按需隐藏数据与异步安全

隐藏合集不再在页面初始化时下载。加载器按实际请求集合判定常规分片或共享隐藏文件，验证目标数组确实存在。独立 `hidden_game` 仍为15个注册点，全国地理概览继续排除游戏坐标，显式游戏视图仍保留红点。

并发搜索保存已经校验的数组引用，在异步完成后核对当前查询代次；释放缓存只针对相同数组，防止旧搜索删除新查询正使用的隐藏数据。省市切换、输入清空或替换会取消过期查询；异步明细加载也核对视图代次，不用旧结果覆盖新范围。取消时同步关闭旧加载提示。
