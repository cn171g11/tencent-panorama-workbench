# 常规街景二级行政区筛选

网页版本：`v2.31.0`（2026-11-08）

## 功能

查看器现在对常规街景提供省级 → 地级市 → 二级行政区三级筛选。选择城市后，若有边界数据，原有区县下拉框会显示对应的区、县、旗、自治县等二级行政区；选择后只显示该区域内的街景点，并自动加载城市数据和缩放地图。

现有点位数组不复制、不改字段。前端继续通过点在面内判定写入临时区县代码，并用该代码过滤结果。隐藏街景仍保持原有独立集合和显示逻辑。

## 边界来源

通过本机代理 `http://127.0.0.1:7897` 下载 GeoAtlas `areas_v3/bound/<adcode>_full.json` 边界。GeoAtlas 与腾讯街景使用相同 GCJ-02 坐标基准，适合直接用于当前查看器。原有 `data_districts.js` 边界保留不变，只补充缺失城市。

- 覆盖城市：297 个
- 二级行政区：2,564 个
- 本批新增城市边界：216 个
- 代表城市：南京、天津、南昌、乌鲁木齐、石家庄、太原、合肥、成都等

7 个特殊管理单元没有独立 GeoAtlas 县级边界文件：429000、441900、442000、460400、469000、620200、659000。它们保留城市级“全部”查看，不生成不可靠的二级行政区按钮。

## 校验

- `data_districts.js` 解析成功：297 个城市、2,564 个边界记录。
- 所有边界记录均包含 `code`、`name` 和有效 `polys`。
- 查看器内嵌 JavaScript 语法检查通过。
- 不改变点位总数和 SID；本批仅更新边界资源与查看器文案/版本。
