## 已退休内容

8 个旧工作台 HTML 和 1 张预览图不再保留在当前源码树，合计 **420,405 字节**。它们没有独立内嵌的街景点位；旧 G212 实时采样、S341 百度展示等旧功能随工作台退休，不代表所有代码原本失效。

代码与预览可从[整理前提交](<https://github.com/cn171g11/tencent-panorama-workbench/tree/03de8f0936612bb8ccaa06836eab7d033d755393>)按清单中的原路径恢复。用户浏览器的 localStorage、原工作区未提交修改均不属于本归档，也未被读取、清空或改写。

## 历史原件的限制

- 各区域原 README 保持历史原文，其中的统计、输出路径、命令及缺失文件名称不是当前执行说明。当前状态以[主说明](<../../README.md>)和[清理记录](<../../docs/repository-cleanup-20261115.md>)为准。
- [新林历史边界](<tencent/xinlin/xinlin-boundary.geojson>)的内部属性为 `地名=漠河县`、`eng_name=Mohe`、`区划码=232723`、`year=2017`，与目录名不符。保留原件供追溯，**不将其当作现行新林边界，不覆盖正式行政区边界**。
- 路线几何不等于原始街景点位。此次只整理源码和资料位置；正式 **59,436,440 点、v2.45.0** 与部署数据提交 `9c751bd80b941096a4cae6df0c93fa1298d6a76f` 不变，不重复导入或审计历史扫描。
- 未来资料仍按来源分开保存，不在此恢复运行页面、点位分片或发布资产。发布器排除此目录，也拒绝当前前端将此处 CSS/脚本列为发布依赖。
